# Console screenshots

Two artifacts, both generated from the console's own renderer, and the states they
were rendered from.

| File | State | What it is for |
|---|---|---|
| `empty-window.svg` / `.png` | a window with **no decisions** | the null state: `rate` reads **no data**, not `0.0%`, with the sentence that says why |
| `populated-window.svg` / `.png` | one connection repeating, one quiet, one learner with evidence | the pair: abstention and served rate from one denominator, credits, the polling alert, and the learner's per-construct row with `serving`/`validated` |

These are **not** browser bitmaps. There is no headless browser in this
environment, so `scripts/console_shot.mjs` walks the vnode tree that
`console.js` produces and lays the text out as SVG, and `scripts/console_shot.py`
draws the same block model to PNG with Pillow (a dev extra: `pip install -e ".[dev]"`). The content and order are the
console's; the CSS layout is not. `KNOWN_GAPS` §30 records the gap and the fix.

Regenerate:

```sh
cd engine

# 1. The state, from a real API response (the test writes it when asked):
mkdir -p /tmp/console-states
ADAPT_CONSOLE_STATE_DIR=/tmp/console-states \
  .venv/bin/python -m pytest tests/test_console.py::test_the_empty_window_renders_to_an_image -q

# 2. The blocks, then the two renderings:
node scripts/console_shot.mjs --state /tmp/console-states/empty.json \
  --out ../docs/console/empty-window.svg --json /tmp/console-states/empty-blocks.json
.venv/bin/python scripts/console_shot.py \
  --blocks /tmp/console-states/empty-blocks.json --out ../docs/console/empty-window.png
```

The test asserts the **text** of the block model, so a font or rasteriser change
cannot fail a correctness test; the PNG is a review artifact and is regenerated by
hand.
